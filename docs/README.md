# Social Images documentation

Social Images makes a share image (`og:image`) for each of your entries from a template you design in the control panel, or write in Twig.

## Setting up

1. [Installation](installation.md): requirements, installing, the field, updating.
2. [Rendering](rendering.md): Browsershot or Cloudflare, renderers, the queue and rate limits.
3. [Choosing templates](choosing-templates.md): which entries get which template, extra sizes, an entry's own image, the fallback.

## Designing

4. [The designer](designer.md): layers, fields in text, pictures, fonts, sizes, previewing and rendering.
5. [Importing and exporting](importing.md): sharing templates as JSON, and [the gallery](https://github.com/1994limited/social-images-statamic/tree/main/gallery).
6. [Code templates](code-templates.md): Twig templates as templates.

## On your site

7. [Twig](tags.md): the image's URL, and meta tags for sites without SEOmatic.
8. [SEOmatic](seo.md): how the image reaches SEOmatic's tags.
